# In Progress

仍在开发中的技能。它们尚未准备好发布 —— 预计会有粗糙之处、破坏性变更和被放弃的实验。在毕业进入某个稳定 bucket 之前，它们被排除在插件和顶层 README 之外。

- **[wayfinder](./wayfinder/SKILL.md)** — 在一个迷雾笼罩的问题中规划一条路线 —— 把一个松散的想法变成一张由调查工单构成的地图，并逐一解决它们，直到通往目标的路径变得清晰。用户调用。
- **[loop-me](./loop-me/SKILL.md)** — 跨多次会话把自己拷问成可实现的工作流规格，把当前目录当作一个带状态的工作区。用户调用。
- **[wizard](./wizard/SKILL.md)** — 生成一个交互式 bash 向导，引导人类走完一套手动流程（初始化设置、一次性迁移、状态转换）—— 打开 URL、捕获值、写入 `.env` 和 GitHub Actions secrets。用户调用。
- **[writing-beats](./writing-beats/SKILL.md)** — 把一篇文章塑造成一段由节拍组成的旅程，采用选择你自己的冒险的方式。挑一个起始节拍，只写那个节拍，然后转向下一个，直到文章抵达一个自然的结尾。
- **[writing-fragments](./writing-fragments/SKILL.md)** — 一种拷问式会话，从你身上挖掘片段 —— 各式各样的写作小块 —— 并把它们追加到单个文档中，作为未来文章的原始素材。
- **[writing-shape](./writing-shape/SKILL.md)** — 拿一个装满原始素材的 markdown 文件，逐段把它塑造成一篇文章，在每一步就格式选择进行论辩。
- **[claude-handoff](./claude-handoff/SKILL.md)** — 把当前对话交接给一个全新的后台智能体，让它立即接手工作，并通过 `claude --bg` 用一份交接摘要作为种子。用户调用。
