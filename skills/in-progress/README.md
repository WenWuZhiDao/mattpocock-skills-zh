# 进行中

仍在开发中的技能。它们尚未准备好发布——预期会有粗糙之处、破坏性改动以及被弃置的实验。在它们晋升到某个稳定分组之前，会被排除在插件和顶层 README 之外。

- **[loop-me](./loop-me/SKILL.md)** — 通过多次会话把自己拷问成可实现的工作流规格，以当前目录作为有状态的工作区。用户触发。
- **[wizard](./wizard/SKILL.md)** — 生成一个交互式 bash 向导，带领用户走完一套手动流程（配置、一次性迁移、状态迁移）——打开 URL、采集数值、写入 `.env` 和 GitHub Actions secrets。用户触发。
- **[writing-beats](./writing-beats/SKILL.md)** — 以“节拍”之旅的方式塑造一篇文章，采用自选冒险的形式。挑一个起始节拍，只写这个节拍，然后转向下一个，直到文章自然收尾。
- **[writing-fragments](./writing-fragments/SKILL.md)** — 一场拷问式会话，从你身上挖掘“碎片”——各式各样的写作素材小块——并把它们追加到单个文档中，作为未来文章的原材料。
- **[writing-shape](./writing-shape/SKILL.md)** — 取一个装有原材料的 markdown 文件，逐段把它塑造成一篇文章，每一步都论证格式选择。
- **[claude-handoff](./claude-handoff/SKILL.md)** — 把当前对话交接给一个全新的后台 agent，它会立即接手工作，并通过 `claude --bg` 用一份交接摘要作为起点。用户触发。
- **[setup-ts-deep-modules](./setup-ts-deep-modules/SKILL.md)** — 把 dependency-cruiser 接入一个 TypeScript 仓库，使每个包都成为深模块——实现隐藏在子文件夹里，只能通过其入口文件访问，测试也通过这些入口来验证。用户触发。
- **[to-questionnaire](./to-questionnaire/SKILL.md)** — 把一个你无法完全回答的决策，变成一份 Markdown 问卷，交给别人异步填写，或在会议上完成。它拷问你的是“这次发送”（发给谁、你需要拿回什么），而不是主题本身。用户触发。
- **[batch-grill-me](./batch-grill-me/SKILL.md)** — 不留情面的访谈，一轮一轮地走完设计树，而不是一次只问一个问题——每一轮都问出前置条件都已确定的整个决策前沿，然后根据你的回答重新计算。用户触发。
