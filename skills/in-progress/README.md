# 开发中（In Progress）

仍在开发中的技能。它们尚未准备好发布 —— 预期会有粗糙之处、破坏性变更和被放弃的实验。在它们晋升到稳定分组之前，会被排除在插件和顶层 README 之外。

- **[review](./review/SKILL.md)** —— 沿两条并行的轴线审查自某个固定点以来的变更：**Standards（标准）**（diff 是否遵循仓库的编码标准？）和 **Spec（规格）**（diff 是否忠实实现了发起它的 issue/PRD？）。
- **[writing-beats](./writing-beats/SKILL.md)** —— 以「节拍（beats）之旅」的方式塑造一篇文章，类似「选择你自己的冒险」。选一个起始节拍，只写那个节拍，然后转入下一个，直到文章走向自然的结尾。
- **[writing-fragments](./writing-fragments/SKILL.md)** —— 一次拷问式会话，从你身上挖掘「片段（fragments）」—— 各式各样的写作小料 —— 并把它们追加到单个文档中，作为未来文章的原材料。
- **[writing-shape](./writing-shape/SKILL.md)** —— 拿一个装着原材料的 markdown 文件，逐段塑造成一篇文章，每一步都对格式选择进行论证。
