description: 不留情面的访谈，一轮一轮地一次性问出整个前沿的所有问题。
disable-model-invocation: true
---

不留情面地拷问用户，直到你们达成共同理解。把它映射为一棵**设计树**：每个决策都会分叉出挂在它下面的那些决策。

按**轮次**处理这棵树。**前沿**是指前置条件都已确定的每个决策——那些你*现在*就能问、无需去猜你还没听到的答案的问题。在一轮里问出整个前沿：给每个问题编号，并给出你推荐的答案。然后等用户回答完再进入下一轮。

用户每一轮的回答都会重塑这棵树——已确定的决策把前沿向外推进，并解锁那些依赖它们的问题。重新计算前沿，问出下一轮。一个问题若其答案取决于本轮尚未解决的另一个问题，就属于*后面的*某一轮，而不是这一轮。

查找*事实*是你的工作，绝不是用户的。当某个前沿问题需要来自环境（文件系统、工具等）的事实时，派出一个子 agent 去查——凡是你自己能查到的，都别问用户。别为此阻塞：一次正在进行的探查是一个未确定的前置条件，因此只有它下游的问题才等待子 agent 回报——前沿上其余的问题现在就问。而*决策*是用户的——把每一个都摆到用户面前并等待。

当前沿为空时，这场会话就完成了：设计树的每个分支都已走过，没有任何东西被默默假定。在用户确认你们已达成共同理解之前，不要据此采取行动。
