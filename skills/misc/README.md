# Misc

我保留但很少使用的工具 —— 在插件中不做推广。

- **[git-guardrails-claude-code](./git-guardrails-claude-code/SKILL.md)** — 设置 Claude Code hooks，在危险的 git 命令（push、reset --hard、clean 等）执行之前拦截它们。
- **[migrate-to-shoehorn](./migrate-to-shoehorn/SKILL.md)** — 把测试文件从 `as` 类型断言迁移到 @total-typescript/shoehorn。
- **[scaffold-exercises](./scaffold-exercises/SKILL.md)** — 创建带有分节、题目、解答和讲解的练习目录结构。
- **[setup-pre-commit](./setup-pre-commit/SKILL.md)** — 设置 Husky 预提交 hook，配合 lint-staged、Prettier、类型检查和测试。
