# Productivity（生产力）

通用的工作流工具，不局限于代码。

- **[caveman](./caveman/SKILL.md)** — 超压缩沟通模式。在保持完整技术准确性的同时，通过去除冗余将 token 用量削减约 75%。
- **[grill-me](./grill-me/SKILL.md)** — 让自己被持续盘问一个计划或设计，直到决策树的每个分支都被解决。
- **[handoff](./handoff/SKILL.md)** — 将当前对话压缩成一份交接文档，让另一个 agent 可以继续工作。
- **[teach](./teach/SKILL.md)** — 跨多个会话教用户一项新技能或概念，把当前目录用作有状态的教学工作区。
- **[write-a-skill](./write-a-skill/SKILL.md)** — 创建结构规范、采用渐进式披露并附带配套资源的新技能。
