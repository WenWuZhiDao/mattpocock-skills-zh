# Productivity

通用的工作流工具，不局限于代码。

## User-invoked

只有当你亲自输入时才可触达（`disable-model-invocation: true`）。

- **[grill-me](./grill-me/SKILL.md)** — 就某个方案或设计接受不留情面的连续追问，直到决策树的每个分支都被解决。
- **[handoff](./handoff/SKILL.md)** — 把当前对话压缩成一份交接文档，让另一个智能体能够接手继续工作。
- **[teach](./teach/SKILL.md)** — 跨多次会话向用户传授一项新技能或概念，把当前目录当作一个带状态的教学工作区。
- **[writing-great-skills](./writing-great-skills/SKILL.md)** — 编写与编辑高质量技能的参考：让技能变得可预测的词汇与原则。

## Model-invoked

模型或用户均可触达（丰富的触发措辞使模型能够主动调用它们）。

- **[grilling](./grilling/SKILL.md)** — 就某个方案或设计不留情面地连续追问用户，直到决策树的每个分支都被解决。
