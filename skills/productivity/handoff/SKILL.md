---
name: handoff
description: 把当前对话压缩成一份交接文档，供另一个智能体接手。
argument-hint: "下一次会话将用于做什么？"
disable-model-invocation: true
---

编写一份交接文档，概述当前对话，让一个全新的智能体能够接手继续工作。保存到用户操作系统的临时目录 —— 而不是当前工作区。

在文档中加入一个"建议技能"章节，列出该智能体应当调用的技能。

不要重复其他产物（PRD、方案、ADR、issue、提交、diff）中已经记录的内容。改为通过路径或 URL 引用它们。

对任何敏感信息（例如 API 密钥、密码或个人可识别信息）进行脱敏处理。

如果用户传入了参数，将其视为对下一次会话所要聚焦内容的描述，并据此调整文档。
