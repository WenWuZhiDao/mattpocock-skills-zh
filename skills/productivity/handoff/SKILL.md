---
name: handoff
description: 将当前对话压缩成一份交接文档，供另一个智能体接手。
argument-hint: "下一次会话将用于做什么？"
---

编写一份交接文档，总结当前对话，让一个全新的 agent 可以继续这项工作。保存到用户操作系统的临时目录中——而不是当前工作区。

在文档中包含一个"建议技能（suggested skills）"部分，列出该 agent 应当调用的技能。

不要重复其他工件（PRD、计划、ADR、issue、commit、diff）中已经记录的内容。改为通过路径或 URL 引用它们。

涂掉任何敏感信息，例如 API key、密码或个人身份信息。

如果用户传入了参数，将其视为对下一个会话将聚焦内容的描述，并据此定制文档。
