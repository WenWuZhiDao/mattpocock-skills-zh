技能之所以存在，是为了从随机系统中拧出确定性。**可预测性**——agent 每次运行都采取相同的_过程_，而非产出相同的输出——是根本美德；下面每根杠杆都服务于它。

**加粗术语**在 [`GLOSSARY.md`](GLOSSARY.md) 中有定义；到那里查阅完整含义。

## 触发

两种选择，各自付出不同的成本：

- 一个**模型触发**技能保留一份 **description**，因此 agent 能自主触发它，_而且_其他技能也能触及它（你仍然可以输入它的名字）。它贡献于**上下文负载**——那份 description 每一轮都坐在窗口里。做法：省略 `disable-model-invocation`，并写一份面向模型、带有丰富触发措辞的 description（“当用户想要……、提到……时使用”）。
- 一个**用户触发**技能把 description 从 agent 的可达范围里剥掉：只有你输入它的名字才能调用它——别的技能都不能。零上下文负载，但它花掉**认知负载**：_你_就是那个必须记住它存在的索引。做法：设 `disable-model-invocation: true`；此时 `description` 变为面向人类——一行摘要，触发列表被剥去。

只有当 agent 必须靠自己触及某技能、或另一个技能必须触及它时，才选择模型触发。如果它永远只靠手动触发，那就把它做成用户触发，不付任何上下文负载。

当用户触发技能繁衍到超出你所能记住时，那堆积起来的认知负载由一个**路由技能**治愈：一个用户触发技能，它为其他技能命名并说明何时该取用每一个。

## 撰写 description

一份模型触发的 **description** 做两件事——陈述这个技能是什么，并列出应当触发它的那些**分支**。每个词都增加**上下文负载**，所以 description 挣得的修剪比正文更狠：

- **把技能的引导词前置**——description 正是它做触发工作的地方。
- **每个分支一个触发词。** 给单个分支改名的同义词是**重复**——“用 TDD 构建功能……请求测试先行的开发”是同一个分支写了两遍。把它们合并；只保留真正不同的分支。
- **删掉正文里已有的身份陈述。** 让 description 只保留触发词，外加任何“当另一个技能需要……”的可达子句。

## 信息层级

技能由两种内容类型构成——**步骤**和**参考资料**——它们自由混合：一个技能可以全是步骤、全是参考资料，或二者兼有。核心决策是用哪一种、以及每一种在**信息层级**上坐在哪里，这架阶梯按 agent 需要材料有多即时来排序：

1. **技能内步骤** — `SKILL.md` 中一个有序的动作，主要层级：agent 按顺序做什么。每个步骤以一个**完成判据**收尾，也就是告诉 agent 工作已完成的那个条件。让它_可检验_（agent 能否分辨完成与未完成？），并在重要之处让它_穷尽_（“每个被改动的 model 都有交代”，而非“产出一份改动清单”）——一个含糊的判据招致**过早完成**。
2. **技能内参考资料** — `SKILL.md` 中一个按需查阅的定义、规则或事实。往往是一组名副其实的平级同侪（某项评审的每条规则都在同一档上）——这是一种恰当的排布，而非坏味道。_本技能全是参考资料。_
3. **外部参考资料** — 被推出 `SKILL.md`、放进一个独立文件的参考资料，经由一个**上下文指针**触及，只有在指针触发时才加载。（跨度从_被披露的_参考资料——像 `GLOSSARY.md` 这样的同级文件，仍属于这个技能——一直到完全的**外部参考资料**，后者存在于技能系统之外，任何技能都可指向它。）

一个要求苛刻的完成判据会驱动彻底的**底层功夫**——agent 在工作中所做的挖掘——无论技能有没有步骤，因为“每条规则都已应用”约束扁平参考资料，正如“每一步都做完”约束一个序列。

往下推得太少，顶部就臃肿；推得太多，你就藏起了 agent 确实需要的材料。那份张力就是整个决策。

**渐进式披露**是沿阶梯往下的那一步——移出 `SKILL.md`、进入一个被链接的文件——好让顶部保持清晰易读。做法：技能文件夹里一个被链接的 `.md` 文件，以它所承载的内容命名（本技能把它的完整定义披露到 `GLOSSARY.md`）。有些技能会以不止一种方式被使用，而每一种不同的方式都是一个**分支**——不同的运行走技能内的不同路径。分支是最干净的披露判准：内联每个分支都需要的东西，把只有部分分支才触及的东西推到指针之后。一个**上下文指针**的_措辞_——而非它的目标——决定 agent 何时、以及有多可靠地触及那份材料。

阶梯决定的是一块材料坐在_多低_的位置，而**就近共置**决定的是它一旦落位_旁边坐着什么_：把一个概念的定义、规则和注意事项归在一个标题之下，而不是散落各处，这样读到其中一部分就会把它的邻居一并带来。

## 何时拆分

**粒度**是你把技能划分得多细，而每种切法都花掉两种负载之一，所以只有当这一刀值回票价时才拆。两种切法：

- **按触发切** — 当你有一个独特的**引导词**、它应当独自触发某技能，或另一个技能必须触及它时，切出一个**模型触发**技能。你要为那份新的、始终加载的 **description** 付出**上下文负载**，所以那份独立的可达性必须值得。
- **按序列切** — 当仍在前方的那些步骤（一个步骤的**后续步骤**）诱使 agent 赶工眼前这一步（**过早完成**）时，切开一串**步骤**。把它们挡在视线之外，鼓励 agent 在当前任务上做更多**底层功夫**。

## 修剪

把每个含义保持在一个**单一事实来源**里：唯一一处权威的地方，这样改变行为就是一处的编辑。

逐行检查**相关性**：它是否仍关乎技能所做之事？

然后逐句而非仅逐行地捕猎**空操作**：对每一个句子单独跑空操作判准，一旦某句不通过，就删掉整句，而不是从中抠词。要下狠手——大多数不通过的散文应当删除，而非重写。

## 引导词

一个**引导词**是一个已经住在模型预训练里的紧凑概念，agent 在运行技能时用它来思考（例如 _lesson_、_fog of war_、_tracer bullets_）。在文本中反复出现（不过未必——一个强的引导词可能只需要一次），它累积起一份分布式的定义，并以最少的 token 锚定一整片行为区域，靠调动模型已经持有的先验。

它双重服务于可预测性。在正文里它锚定_执行_：每当那个词出现，agent 都伸手去取同一种行为。在 description 里它锚定_触发_：当同一个词也住在你的提示、文档和代码里时，agent 会把那份共享语言与这个技能关联起来，从而更可靠地触发它。

去捕猎把技能重构为使用引导词的机会。在三处被逐字展开的一个三元组（**重复**）、一份花掉一整句去指向一个想法的 description——每一处都是一段乞求**坍缩**成单个 token 的文字。示例包括：

- “fast, deterministic, low-overhead” -> _tight_ ——一个品质在一个阶段里被反复重述——坍缩进一个预训练词（一个 _tight_ 循环）。
- “a loop you believe in” -> _red_ ——把一个模糊的门槛转换成一个二元的可观测状态（循环在 bug 上变_红_，或者没变）。

你赢两次：更少的 token，_而且_一个更锐利、供 agent 挂住其思考的钩子。假设每个技能都携带着引导词能退役的重述——去找出来。

## 失败模式

用它们来诊断用户可能在这个技能上遇到的问题。

- **过早完成** — 在一个步骤真正完成之前就结束它，注意力溜到了_已经完成_上。防御，按次序：先磨锐完成判据（廉价、局部）；只有当它不可约地模糊_且_你观察到了赶工时，才通过拆分（序列切法）隐藏后续步骤。
- **重复** — 同一个含义出现在不止一处。花掉维护和 token，并把一个含义在阶梯上的显著性抬高到超过它真实的排位。
- **沉积** — 因为添加让人感觉安全而移除让人感觉冒险，而沉淀下来的陈旧层。它是任何缺乏修剪纪律的技能的默认归宿。
- **蔓延** — 一个单纯太长的技能，哪怕每一行都是活的、独一无二的。它损害可读性和可维护性，并浪费 token。解药是那架阶梯：把**参考资料**披露到指针之后，并按**分支**或序列拆分，好让每条路径只携带它需要的东西。
- **空操作** — 一行模型默认就会遵从的指令，于是你付出负载却什么也没说。判准：它相对默认是否改变行为？一个弱引导词（_be thorough_，而 agent 本就相当彻底）是一个空操作；修法是一个更强的词（_relentless_），而不是换一种技法。
- **否定式** — 靠禁止来引导会适得其反：_别去想一头大象_会把大象点进画面，使它更可用而非更不可用。提示**正面**——陈述目标行为，好让被禁的那个从不被说出口；只在你无法正面表述的行为上把禁令作为一道硬护栏保留，即便如此也要把它与该做的事配对。
