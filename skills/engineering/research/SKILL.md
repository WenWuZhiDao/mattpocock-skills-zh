name: research
description: 针对高可信度的一手来源调查一个问题，并把发现记录为仓库中的一个 Markdown 文件。当用户想要调研某个主题、收集文档或 API 事实，或把阅读跑腿活交给后台 agent 时使用。
---

启动一个**后台 agent** 来做这项研究，好让它读的时候你继续干活。

它的任务：

1. 针对**一手来源**调查这个问题——官方文档、源代码、规范、第一方 API——而不是它们的二手转述。把每一条论断都追溯回拥有它的来源。
2. 把发现写进单个 Markdown 文件，为每条论断标注来源。
3. 把它存到仓库已经存放此类笔记的地方；匹配既有约定，如果没有，就放在一个合理的地方并说明放在了哪里。
