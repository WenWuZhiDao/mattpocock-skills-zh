# 阶段边界

一个**阶段**是会话内部的一块工作——拷问、实现、QA。这个定义是故意模糊的：当你觉得*「好，这块搞定了」*时，一个阶段就结束了。

**阶段边界**是两个阶段之间的间隙，也是这个决策唯一该出现的地方。阶段进行到一半时没有决策可做——要么继续，要么把剩下的工作拆分给子 agent。在阶段中途压缩会让 agent 丢失思路。

## 五个选项

| 选项         | 作用                                                            |
| ------------ | --------------------------------------------------------------- |
| **继续** | 留在会话里。完全没有上下文切换。                    |
| **`/clear`** | 清空上下文窗口，从零开始。                  |
| **`/handoff`** | 写一个可移植的 markdown 文件，并用它在任何地方引导一个新会话。 |
| **子 agent** | 把任务发送到它自己的上下文窗口，并取回一份报告。     |
| **`/compact`** | 压缩当前上下文，并用摘要引导一个全新的会话。  |

## 决策树

在边界处自上而下地推进。第一个**是**胜出。

**1. 你能在这个会话里继续吗？** 两件事让答案为「是」：下一阶段需要把这一阶段当作**一手来源**，或者你还剩下足够的[聪明区间](https://www.aihero.dev/ai-coding-dictionary/smart-zone)（约 150k tokens）来容纳下一阶段。拷问 → 实现是标准的「是」：实现想要逐字的推理，而不是它的摘要。继续不花任何代价、也不损失任何东西，所以在考虑其他一切之前先排除它。

**2. 上下文与接下来的事无关吗？** 这个会话里的一切——探索、决策、死胡同——都是可丢弃的吗？如果是，就 **`/clear`**。它是棋盘上最便宜的一步：不花时间，把整个窗口还给你。`/clear` 也不是终结——旧会话仍可恢复。

搞错这一点的代价是单向的。清掉一个*相关*的上下文，你就丢失了所构建之物背后的**为什么**，而无论回头读多少遍 diff 都换不回来。

**3. 你需要交接吗？** `/handoff` 适用面很窄。只有当你在做以下事情时才需要它：

- 切换到**新的 harness**（Claude → Codex），
- 迁移到**新目录**或新仓库，
- 把工作发给**同事**，
- 或者在**阶段中途**发现一个旁支任务，想在不打乱当前工作的情况下把它分叉出去。

那个列表就是这一条的全部。`/handoff` 换来的是**可移植性**——一个能随身携带的文件。如果没有东西需要移动，你就不需要它。

**4. 这个任务能 AFK（离开键盘）完成吗？** 它是否界定得足够紧凑，能在你离开键盘、不做引导的情况下运行？那就把它发给**子 agent**，让这个会话保持原样。自动化审查是标准情形：agent 读 diff 并报告，它做这件事时不需要你。

**5. 否则，`/compact`。** 相关的上下文、同一个 harness、同一个目录，而且你需要留在环里——这就是决策树落脚的地方，而且它经常落在这里。给它一条指令（`/compact we're going to QA this area`），让摘要保留下一阶段所需要的东西。

`/compact` 是**默认项，而非首选项**。它位于底部，因为它上面的四个问题要么更便宜、要么更精确。人们从这里起步时的失败模式，是一个全新的会话对某个被摘要压平的决策自信地做出了错误判断。

## 一手来源与二手来源

除了**继续**之外的每一步，都会把**一手来源**变成**二手来源**——真实发生过的会话，被它的一份摘要替换掉。这笔交换的形状总是一样的：

| 来源                            | 信息量 | 噪声 | 腾挪空间 |
| --------------------------------- | ----------- | ----- | ------------ |
| 一手（继续）                | 完整        | 大量  | 很小       |
| 二手（`/compact`、`/handoff`） | 有损        | 较少  | 很大       |

这就是为什么问题 1 排在最前面。只有当留下来的代价高于它带来的好处时，你才去付这份有损的代价。

## 这些都是判断题

这些问题并非客观——每一个都掺入了品味，同一个边界在两天里可能走向两种答案。价值在于**按顺序**发问，在边界处而不是在工作进行到一半时发问。
