## 它做什么

`triage` 让你项目跟踪器上的 issue 走过一个由分诊角色构成的小型**状态机**——给它们分类、核实其论断、必要时把它们拷问成型，并留下一份 ready-for-agent 的简报。

它绝不盲目贴标签。每个分诊过的条目都恰好带一个**类别**角色（`bug` / `enhancement`）和一个**状态**角色（`needs-triage`、`needs-info`、`ready-for-agent`、`ready-for-human`、`wontfix`），并且它*推荐并等待*——它带着推理告诉你它对类别和状态的判断，然后只按你的指示行动。在任何东西被提升到 `ready-for-agent` 之前，它会先核实论断：一个 bug 会被复现，一个 PR 会被检出并运行。

## 何时使用它

你通过输入 `/triage` 并用自然语言描述你想要什么来调用它——智能体不会自行触发它。"给我看任何需要我关注的东西"、"我们来看看 #42"、"把 #42 移到 ready-for-agent"。

当你的 issue 跟踪器里有原始、未经评估的报告，而你想把它们整理、核实，并变成智能体或人类能接手的工作时，就用它。若要把一段敲定的对话变成一份全新的规格，请用 [to-spec](https://aihero.dev/skills-to-spec)；若要把一份已有的规格拆成工单，请用 [to-tickets](https://aihero.dev/skills-to-tickets)。`triage` 是反方向的——它处理*已经*落进跟踪器的东西。

## 前置条件

`triage` 读写你的 issue 跟踪器，所以 [setup-matt-pocock-skills](https://aihero.dev/skills-setup-matt-pocock-skills) 必须先配置好跟踪器和标签映射。上面的角色名是**规范的**——你跟踪器里实际的标签字符串可能不同，而那份映射正是 setup 所提供的。该配置还决定外部 PR 是否算作一个请求来源，以及谁算作外部。

## PR 是附带了代码的 issue

在跟踪器把外部 pull request 视为一个请求来源的地方，`triage` 让它们走过*同一台*状态机：同样的类别角色、同样的状态、同样的转换——只是状态改为对照差异来判读，而非对照一份报告。`ready-for-agent` 意味着已附上简报、智能体应对代码采取下一步；`ready-for-human` 意味着它已可合并。发现只会浮现外部 PR，但一个被显式点名的 PR 无论作者是谁总会被分诊。

## 先核实，再简报

把 `triage` 与临时贴标签区分开来的那一步是核实。它按报告者的步骤复现 bug，或者检出 PR 并运行测试，然后回报：附带一条代码路径确认了、失败了，或者细节不足（这本身就是一个强烈的 `needs-info` 信号）。它还运行两项代码库检查——**冗余**（这个是否已经实现了？那就是 `wontfix`）和**先前拒绝**（`.out-of-scope/` 是否已经说了不？）。一次确认了的核实能做出一份强得多的智能体简报；猜测则不能。

## 它生效的标志

- 它触及的每个条目最终都恰好带一个类别角色和一个状态角色——绝不为零，绝不有两个相冲突的状态。
- 它带着推理递给你一份推荐并等待，而不是自作主张地重新贴标签。
- 在任何东西到达 `ready-for-agent` 之前，bug 会被复现、PR 会被运行。
- 它发到跟踪器的每一条评论都以免责声明 `> *This was generated by AI during triage.*` 开头。

## 它的位置

`triage` 是对你 issue 跟踪器的**定期维护**环节——每当报告堆积时就运行它，好让队列保持有序、让 `ready-for-agent` 那一列值得信任。它坐落在跟踪器的最前端，在构建链的上游：它写出的简报正是 [tdd](https://aihero.dev/skills-tdd) 日后拾起来实现的东西。当一个请求需要磨利时，它倚赖 [grilling](https://aihero.dev/skills-grilling) 和 [domain-modeling](https://aihero.dev/skills-domain-modeling)，一次一个问题地把它拷问成型。它亲近的邻居是 [to-spec](https://aihero.dev/skills-to-spec)，后者从一段全新的对话来填充跟踪器，而 `triage` 处理的是已经在那里的东西。当你不确定该用哪个技能或流程时，[ask-matt](https://aihero.dev/skills-ask-matt) 会为你指路。
