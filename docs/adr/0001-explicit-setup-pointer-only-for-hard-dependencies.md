# 仅对硬依赖给出显式的 `/setup-matt-pocock-skills` 指引

工程类技能依赖于由 `/setup-matt-pocock-skills` 播种的每仓库配置（问题追踪器、triage 标签词汇、领域文档布局）。有些技能没有该配置就无法有意义地运行——它们必须发布到特定的问题追踪器，或应用特定的标签字符串。另一些技能只用它来打磨输出（词汇、ADR 意识），即便没有也能优雅降级。

我们把这些技能分为**硬依赖**和**软依赖**两类：

- **硬依赖**（`to-issues`、`to-prd`、`triage`）——包含一句明确的提示：_"……应该已经提供给你了——如果没有，请运行 `/setup-matt-pocock-skills`。"_ 没有这套映射，输出就是错的，而不仅仅是模糊。
- **软依赖**（`diagnose`、`tdd`、`improve-codebase-architecture`、`zoom-out`）——仅以含糊的措辞引用"项目的领域术语表"和"你正在改动区域的 ADR"。如果这些文档不存在，技能仍然可用，只是输出不那么精准。

这种划分让软依赖技能保持 token 轻量，并避免把 setup 指引生搬硬套到那些它并不起承重作用的地方。
