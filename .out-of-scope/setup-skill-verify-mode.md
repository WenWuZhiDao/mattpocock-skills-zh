# `setup-matt-pocock-skills` 的验证/检查模式

本项目不会为 `setup-matt-pocock-skills` 添加专门的验证/检查模式（或单独的验证技能）。

## 为什么这超出范围

第二个技能——或一个 `--verify` 参数——用于检查 `docs/agents/*.md` 制品是否仍与种子模板 schema 匹配，这会重复现有 setup 技能已经在对话中处理的工作。

预期的工作流是：**运行 `/setup-matt-pocock-skills` 并让它验证你当前的设置。** 该技能由提示词驱动，因此维护者可以将它限定为一次验证过程（"不要重写任何东西，只需把我现有的文件与当前的种子模板对比，并报告偏差"），而不需要单独的代码路径。添加一个参数或一个同级技能，会把一个本已可通过自然语言入口表达的功能的覆盖面拆散。

将配置管理保持在单一技能中，也避免了当种子模板演进时两个技能彼此漂移所带来的维护成本。
